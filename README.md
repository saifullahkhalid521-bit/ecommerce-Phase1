# MyStore — Phase 1 E-Commerce Store

A frontend-only e-commerce demo built with vanilla HTML, CSS, and JavaScript 
to practice core JS concepts, API integration, and state management.

## ✨ Features

- Product listing with search, category filter, price/rating sort
- Product detail page with dynamic routing (?id=X)
- Cart with quantity controls, subtotal, and total
- Wishlist with move-to-cart functionality
- Demo checkout with form validation and order confirmation
- Responsive design for mobile and desktop
- Cart and wishlist persisted via localStorage

### Installation
1. Clone the repository:  
   ```bash
   git clone https://github.com/yourusername/mystore.git
   ``` 
2. Navigate to the project directory:  
   ```bash
    cd mystore
    ``` 
3. Open `index.html` in your web browser to view the application.
