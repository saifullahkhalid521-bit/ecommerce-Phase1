About MyStore

A learning project for practicing vanilla JavaScript

Our Story

MyStore is a fictional e-commerce website created as a learning project to practice vanilla JavaScript, HTML, and CSS. The goal of this project is to build a simple yet functional online store that allows users to browse products, view product details, and add items to their shopping cart.

Technologies Used

HTML5 CSS3 JavaScript Fetch API LocalStorage

Features

  • Product listing with search/filter
  • Product detail views
  • Shopping cart functionality
  • Wishlist management
  • Responsive design for all devices
